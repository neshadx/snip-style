# SnipStyle ✨

SnipStyle is a sleek and modern CSS snippet UI toolkit built with React. It helps developers quickly copy and use beautifully crafted CSS styles such as button designs and shadow effects.

---

## 🚀 Features

- ⚡ **One-Click Copy**: Instantly copy button or shadow CSS.
- 🎨 **Beautiful UI**: Modern, responsive layout with custom styling.
- 🧩 **Reusable Components**: Modular code structure.
- 📱 **Mobile Friendly**: Fully responsive across devices.
- 🌈 **Custom Styles**: Easily extend with your own buttons and shadows.

---

## 🛠 Tech Stack

- **Frontend**: React.js, CSS3
- **Routing**: React Router
- **Icons**: React Icons / Flaticon
- **Font**: Google Fonts (Fira Code)

## 📦 Getting Started

This project was created using **Create React App**.

### Available Scripts

In the project directory, you can run:

- **`npm start`** or **`npm run dev`**
  Runs the app in development mode.  
  Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

- **`npm run build`**  
  Builds the app for production in the `build` folder.  
  React will be optimized and bundled for deployment.

- **`npm test`**  
  Launches the test runner in watch mode.

- **`npm run eject`**  
  ⚠️ Ejecting is a one-way operation. You get full control but cannot go back.
